# Nostrange: Private Decentralized AI Matchmaker

**Nostrange** یک پلتفرم همسریابی و دوستیابی غیرمتمرکز، متن‌محور و مبتنی بر پروتکل **Nostr** و هوش مصنوعی شخصی کاربر است. 

این پروژه با بالاترین استانداردهای امنیتی و حریم خصوصی در سیستم‌عامل Android با زبان **Kotlin**، رابط کاربری مدرن **Jetpack Compose (Material 3)** و دیتابیس محلی **Room** توسعه داده شده است.

---

## 🛡️ اصول بنیادین و غیرقابل مذاکره (Core Philosophy)

1. **بدون سرور مرکزی (Zero Central Server):** توسعه‌دهنده هیچ سرور، بک‌اند، یا پایگاه داده مرکزی ندارد. تبادل داده‌ها صرفاً از طریق رله‌های توزیع‌شده Nostr انجام می‌شود.
2. **بدون هوش مصنوعی مرکزی (Zero Central AI):** هیچ مدل AI مرکزی یا API اختصاصی وجود ندارد. تحلیل و استدلال عمیق با هوش مصنوعی انتخابی خود کاربر (مانند ChatGPT، Gemini، Grok یا Agent سیستم) انجام می‌پذیرد.
3. **کاملاً بدون عکس و رسانه (Zero Media Guarantee):** هیچ قابلیت، UI، فیلد دیتابیس یا ایونت Nostr مربوط به تصویر، آواتار، دوربین یا گالری وجود ندارد. ارتباط کاملاً ساختاریافته و متنی است.
4. **فیلترینگ سخت‌گیرانه داده‌های هویتی و تماس (Strict Privacy Enforcement):** نام، نام خانوادگی، شماره تماس، ایمیل، آدرس و شناسه‌های شبکه‌های اجتماعی (تلگرام، اینستاگرام و...) در سطح کلاینت و پیش از انتشار در Nostr یا ورودی AI به صورت خودکار حذف و رد می‌شوند.
5. **کلیدها در انحصار کاربر (Hardware-Backed Keystore):** کلید خصوصی Secp256k1 در Android Keystore ذخیره شده و هرگز از دستگاه خارج نمی‌شود.

## 🔄 پایپ‌لاین Matchmaking محلی (Candidate Pipeline)

```
۱۰,۰۰۰ پروفایل دریافت شده از Nostr
       ↓
[ Hard Filters محلی ] (جنسیت متقابل، بازه سنی، عدم حضور در deal-breakers)
       ↓
۳,۰۰۰ کاندیدای واجد شرایط
       ↓
[ Initial Compatibility Scoring محلی ] (فرمول وزن‌دار سازگاری متقابل دوطرفه A ↔ B)
       ↓
۵۰۰ کاندیدای برتر محلی
       ↓
[ تولید پرامپت ساختاریافته فشرده برای AI / Agent کاربر ]
       ↓
[ تحلیل و استدلال عمیق هوش مصنوعی خارجی ]
       ↓
۵۰ کاندیدای رتبه‌بندی شده نهایی همراه با دلایل سازگاری
       ↓
درخواست آشنایی رمزنگاری شده (Introduction Protocol)
       ↓
چت خصوصی سرتاسر رمزنگاری شده (NIP-44)
```

## 💬 جریان کاربری اپلیکیشن (User Flow)

1. **تب Me (پروفایل من):** 
   - مصاحبه گفتگویی مرحله‌به‌مرحله به جای فرم‌های قدیمی.
   - تولید پرامپت با دستورات سخت‌گیرانه حذف اطلاعات هویتی.
   - دریافت و اعتبارسنجی JSON از هوش مصنوعی و انتشار ایونت عمومی در Nostr.
2. **تب Matches (همسان‌ها):**
   - مشاهده آمار کاندیداها، تولید پرامپت ۵۰۰ کاندیدای برتر، وارد کردن خروجی ۵۰ مورد برتر AI.
   - مشاهده کارت‌های بدون عکس با امتیاز سازگاری و دلایل هوش مصنوعی.
   - دکمه «درخواست آشنایی» برای ارسال اولین پیام خودکار به طرف مقابل.
3. **تب Chats (گفتگوها):**
   - لیست گفتگوها بر اساس Pubkey و درصد سازگاری.
   - دیسکلیمر بالای صفحه درباره متادیتای رله‌ها و رمزنگاری NIP-44.
   - منوی سه نقطه برای بلاک کردن اسپم.
4. **تب Settings (تنظیمات):**
   - مشاهده و کپی کلید عمومی `npub`.
   - افزودن و مدیریت رله‌های Nostr.
   - پاک‌سازی کش کاندیداها و بررسی تضمین‌های حریم خصوصی.

## 🧪 اجرای تست‌ها (Unit Tests)

پروژه شامل پوشش کامل تست‌های واحد برای موارد زیر است:
- `PrivacyEnforcerTest`: حذف فیلدهای ممنوعه و پاک‌سازی Regex ایمیل، تلفن و شناسه‌ها.
- `ProfileJsonSchemaTest`: بررسی محدوده‌های عددی 0 تا 100 و اعتبارسنجی ساختار.
- `MatchingResultValidatorTest`: تشخیص و رد Pubkeyهای جعلی یا نامعتبر در پاسخ AI.
- `CompatibilityAndFilterTests`: تست Hard Filtering، سازگاری متقابل و رتبه‌بندی کاندیداها.
- `CryptographyAndNostrTests`: تست امضای Schnorr BIP-340، کلیدهای Bech32 و رمزنگاری NIP-44 v2.

برای اجرای تست‌ها در ترمینال یا Android Studio:
```bash
./gradlew test
```
یا باز کردن پروژه در **Android Studio** و زدن دکمه Run Tests.
